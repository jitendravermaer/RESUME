# RESUME

## Overview
This repository contains my personal resume created using HTML and CSS. The goal is to have a clean, professional, and responsive design that can be easily viewed on various devices and browsers.

## Contents
The repository includes the following files:
- `index.html`: The main HTML file containing the structure of the resume.
- `styles.css`: The CSS file used for styling the resume.

## Technologies Used
- **HTML**: The primary language used for structuring the resume content.
- **CSS**: Used for styling the resume to give it a professional look.
